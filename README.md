# Company Sales Data: Matplotlib Exercises

This project plots the 12 months in `company_sales_data.csv` using Matplotlib.

## Exercises

1. **Monthly total profit:** a line plot of `total_profit` against `month_number`.
2. **Bathing soap and facewash:** two subplots showing `bathingsoap` and `facewash` sales against `month_number`.

## Run

Install Matplotlib if needed, then run the script from this folder:

```bash
python3 -m pip install matplotlib
python3 sales_exercises.py ../company_sales_data.csv
```

The script saves both charts in `sales_plots/`. You can pass a different CSV path or use `--output-dir` to change where the plots are saved.
